# 北市文山社大 志工數位小幫手 📱

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Mobile Friendly](https://img.shields.io/badge/Device-Mobile--First-blue)

專為 **台北市文山社區大學** 志工打造的行動端入口導覽網頁。本專案旨在透過簡約的介面，整合簽到工具、AI 輔助助手以及校園平面圖資，協助志工在服務期間能更快速、精確地完成各項任務。

---

## 🌟 核心功能

本工具針對志工服務的五大核心需求進行整合：

1.  **📷 快速開啟相機**：一鍵喚醒手機後置相機，方便進行 OCR 辨識或現場拍攝。
2.  **📝 簽到退助手 (撇步版)**：導引至志工簽到/簽退優化工具，簡化繁瑣流程。
3.  **🤖 AI 智能輔助**：整合 Gemini AI 資源，隨時解決簽到過程中的疑難雜症。
4.  **🗺️ 校園圖資整合**：收錄景美國中、木柵國中校園平面圖，確保服務導引不迷路。

---

## 🚀 快速上手

您可以直接透過手機瀏覽器訪問已部屬的網頁連結（見下方 [專案連結](#專案連結)），或將網頁「加入主畫面」作為 Web App 使用，體驗更佳。
